# Personal Portfolio Site

A responsive single-page portfolio built during a web development internship with Codsoft (2023).

Hand-written HTML, CSS and JavaScript, no framework, no CSS library. Layout adapts across breakpoints via `mediaquery.css`.

## Files

| File | Purpose |
|---|---|
| `style.css` | Base styles and layout |
| `mediaquery.css` | Responsive breakpoints |
| `script.js` | Interactive behaviour |

## Running it

Clone the repo and open the HTML file in a browser. No build step, no dependencies.
